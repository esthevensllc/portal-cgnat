# Despliegue offline

La guía completa y canónica de instalación, actualización, rollback y
migración productiva está en [`../README.md`](../README.md).

Para pasar de cuatro a siete colectores en una instalación existente, usar
únicamente el [runbook de ampliación](../README.md#ampliar-de-cuatro-a-siete-colectores-runbook),
que reúne configuración, validación y reversión en una sola secuencia.

Este archivo se conserva como enlace estable para documentación o marcadores
existentes. No se deben duplicar aquí los pasos operativos, porque podrían
quedar desactualizados respecto del `README.md`.
